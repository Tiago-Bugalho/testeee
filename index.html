Refracta Installer — preparando a próxima ISO
Este painel instala o Refracta Installer no seu Debian personalizado para que a próxima ISO do Polius OS possa ter um instalador.

1. Criar a pasta de trabalho

mkdir -p ~/refracta-installer && cd ~/refracta-installer

2. Baixar o Refracta Installer Base

Versão publicada pelo projeto Refracta. 
wget https://sourceforge.net/projects/refracta/files/tools/refractainstaller-base_9.6.6_all.deb/download -O refractainstaller-base.deb

3. Baixar a interface gráfica

wget https://sourceforge.net/projects/refracta/files/tools/refractainstaller-gui_9.6.6_all.deb/download -O refractainstaller-gui.deb

4. Instalar os dois pacotes

O GUI depende do pacote base. 
sudo apt install ./refractainstaller-base.deb ./refractainstaller-gui.deb

5. Abrir o instalador

sudo refractainstaller-yad
⚠️ Importante: nesta etapa você só precisa confirmar que o instalador abre corretamente. Não é necessário instalar o sistema no seu Debian atual.
✅ Depois de confirmar que o instalador abre, gere uma nova ISO com o Refracta Snapshot. Essa será a versão que você poderá testar no polius-test.qcow2.

6. Gerar a nova ISO

sudo refractasnapshot-gui
