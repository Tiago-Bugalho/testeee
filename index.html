Refracta Snapshot — geração da primeira ISO
⚠️ Execute os comandos dentro do Debian que contém o seu Polius OS. A página apenas copia os comandos; ela não executa nada automaticamente.

1. Criar a pasta de trabalho

mkdir -p ~/refracta && cd ~/refracta

2. Baixar o Refracta Snapshot Base

Pacote base necessário para o Snapshot. 
wget https://sourceforge.net/projects/refracta/files/tools/refractasnapshot-base_10.4.3_all.deb/download -O refractasnapshot-base.deb

3. Baixar a interface gráfica

wget https://sourceforge.net/projects/refracta/files/tools/refractasnapshot-gui_10.4.1_all.deb/download -O refractasnapshot-gui.deb

4. Instalar o Refracta Snapshot

sudo apt install ./refractasnapshot-base.deb ./refractasnapshot-gui.deb

5. Verificar o espaço disponível

Confira se há bastante espaço livre antes de criar a ISO. 
df -h

6. Abrir o Refracta Snapshot

sudo refractasnapshot-gui

7. Depois, gerar a ISO

Dentro do Refracta Snapshot, use a opção de criação do snapshot. O programa cria uma imagem Live baseada no sistema que está rodando. 
sudo refractasnapshot
✅ Ao terminar, procure a ISO gerada pelo Refracta e renomeie para polius-os.iso, caso ela tenha outro nome.
