Polius OS

Correção do Refracta Installer para Debian 13 + KDE Plasma + SDDM. Faça o instalador da sua ISO desativar corretamente o login automático no sistema instalado.
Refracta Installer 9.6.6 → patch SDDM

⚠️ Qual é o problema?

A opção Disable automatic login to desktop pode aparecer marcada, mas o instalador original não tratava corretamente o SDDM usado pelo KDE Plasma.

O resultado é que a instalação termina, reinicia e entra diretamente no desktop, sem mostrar a tela de login.

🚀 Como corrigir no Debian original

Execute os comandos abaixo no Debian que você usa para criar as ISOs do Polius OS.

1

Fazer backup do instalador atual

Assim você pode voltar para a versão original caso necessário.

Terminal
sudo cp /usr/bin/refractainstaller-yad /usr/bin/refractainstaller-yad.backup
2

Baixar a versão corrigida

Esta versão contém a correção do autologin para SDDM/KDE.

Terminal
sudo wget -O /usr/bin/refractainstaller-yad https://raw.githubusercontent.com/AtmanActive/Refracta-on-Debian-13-with-KDE/main/refractainstaller_patched/9.6.6.20/refractainstaller-yad
3

Corrigir proprietário e permissões

Terminal
sudo chown root:root /usr/bin/refractainstaller-yad
sudo chmod 755 /usr/bin/refractainstaller-yad
4

Verificar a correção do SDDM

Terminal
sudo grep -n -A12 "#sddm" /usr/bin/refractainstaller-yad
O resultado deve mostrar código relacionado a /etc/sddm.conf e/ou /etc/sddm.conf.d/.

💿 Depois, gere a ISO do Polius OS

Não altere manualmente o SDDM do Debian original se ele já está funcionando corretamente. A ideia é levar o instalador corrigido para dentro da ISO.

5

Gerar uma nova ISO

Terminal
sudo refractasnapshot-gui
6

Instalar a nova ISO

✅ Inicie Polius OS (default)
✅ Abra Instalar Polius OS
✅ Entre no modo Expert, caso necessário
✅ Deixe Disable automatic login to desktop marcado
✅ Instale no disco escolhido

✅ Resultado esperado

Depois da instalação e do reboot, o Polius OS deverá iniciar no SDDM e apresentar a tela de login em vez de entrar automaticamente no desktop.

👤 Usuário + senha
